# ADR-0070: 新進同仁專屬全寬圖文選單與精煉入職動線 (Newcomer Onboarding Rich Menu & Streamlined Enrollment Flow v2.30.0)

> **狀態 (Status)**: 已採納 (Accepted) | **生效版本 (Version)**: `v2.30.0`  
> **領域分類 (Category)**: `Onboarding & LIFF` / `LINE Rich Menu` / `PBAC & Role Projection` / `UX Architecture`

---

## 決策內容與架構推演 (Decision Record)

- **核心背景與實機體驗斷點**：
  - 在 `v2.29.0` 實裝加好友硬閘門後，使用者於真機掃碼測試發現：點擊【第一步：加入打卡官方帳號好友】後，LINE 會自動關閉當前 LIFF 視窗跳轉至原生官方帳號頁面，造成用戶加完好友後留在 LINE 聊天室，原本的 LIFF 入職視窗已消失，無法繼續點擊「確認入職」按鈕。
  - 同時，在尚未加好友時，於 LIFF 頁面下方展示一個反灰鎖定、無法點擊的「第二步：確認加入考勤系統」按鈕顯得多餘且產生無謂的視覺混淆。
- **三重圖文選單生態架構 (Triple Rich Menu Architecture)**：
  - **新進同仁全寬選單 (`ONBOARDING_RICH_MENU_ID`)**：
    - 尺寸為 1 排 3 格寬（2500×843），整排滿版單一巨大按鈕，標示純粹無瑕之大字級繁體中文【新進同仁入職登記】（徹底拔除未支援之 unicode emoji 方塊）。
    - 點擊動作配置 URI：`https://liff.line.me/2011328810-vjUUBSYA?tab=onboarding`。
    - **設為 LINE 官方帳號預設選單 (`DEFAULT`)**：所有首次加好友的新進同仁或尚未歸屬門市的訪客，進入聊天室看到的唯一常駐選單即為【新進同仁入職登記】。
  - **在職員工選單 (`EMPLOYEE_RICH_MENU_ID`)**：
    - 1 排 3 格（考勤打卡、排班月曆、線上簽核）。
  - **門市主管選單 (`MANAGER_RICH_MENU_ID`)**：
    - 2 排 4 格超集選單（上排 3 格個人考勤，下排門市管理工作台）。
- **狀態機動態流轉與意圖記憶 (Intent & State Transition)**：
  1. **門市掃碼意圖持久化**：新進同仁於門市現場掃描立牌 QR Code（帶有 `?cid=...`）時，LIFF 自動將門市代碼存入 `localStorage`（`line_checkin_pending_cid`）。
  2. **純粹單一按鈕 UI**：
     - 若未加好友：僅展示【加入打卡官方帳號好友】大按鈕與引導說明，**徹底隱藏（砍掉）無法點擊的確認入職按鈕**。
     - 若已加好友：僅展示翡翠綠置中【確認加入考勤系統】大按鈕，隱藏加好友按鈕。
  3. **聊天室自動接力**：用戶加完好友後身在聊天室，直接點擊下方常駐的全版【新進同仁入職登記】大按鈕，喚起 LIFF 自動提取剛才掃碼暫存的門市代碼，直接呈現綠色確認入職按鈕。
  4. **入職即刻切換選單**：`POST /api/v1/employee/join` 入職成功後，後端透過 LINE Messaging API 自動將該同仁之專屬選單提升為【員工選單】（或主管選單），徹底告別新人選單。
  5. **離職/踢出自動歸位**：解除員工身分或未綁定者，調用 `DELETE /v2/bot/user/{userId}/richmenu` 後，LINE 自動無縫回歸預設之【新進同仁入職選單】。

---

## 影響與防護效益 (Consequences)

1. **徹底解決 WebView 跳轉關閉問題**：將加好友跳轉造成的「流程中斷」，轉化為 LINE 官方生態系最自然的「聊天室選單接力」，體驗流暢無斷點。
2. **視覺資訊降噪**：LIFF 頁面未加好友時不再呈現鎖定無效按鈕，介面簡潔且目標明確。
3. **字型與符號相容性**：去除特殊 unicode emoji，採用高品質點陣/向量渲染之微軟正黑體粗體，任何品牌的手機螢幕皆 100% 正常顯示。
